— Pipeline Overview —

How It Works

A four-stage NLP pipeline transforms raw legal text into structured, actionable intelligence.

01
📋

Paste Contract Text

User inputs raw contract text via the web interface. Supports agreements, NDAs, service contracts and more.

02
🔍

Regex Pattern Matching

Domain-specific regular expressions scan for dates, monetary amounts, governing law clauses and other structured patterns.

03
🧠

spaCy NER Pipeline

The en_core_web_sm model identifies Organizations (ORG), Dates (DATE), Money (MONEY), and Locations (GPE) in context.

04
📊

Structured Clause Output

Results are compiled into 8 clause categories and displayed in a clean card grid with color-coded confidence indicators.
